# 项目规则

- 版本：`v1.2`
- 日期：`2026-08-30`
- 状态：`CURRENT / NORMATIVE`
- 当前产品状态：`源码/docs/PRODUCT_CURRENT.md`
- 完整实施路线：`源码/docs/AUTONOMOUS_PRODUCT_MASTER_PLAN.md`

本项目只保留两个总原则：**工作以推进为默认，外部效果必须可归因、可撤回、可核对。**

## 1. 以成熟产品为默认终点

产品完成标准不是协议、页面、固定 fixture 或单次演示，而是能够由定时任务反复唤醒，
在真实课程上完成感知、世界状态更新、择机、语言实现、重读让位、受控执行和结果回流，
并在进程重启、重复唤醒和局部失败后保持幂等与可恢复。

P3A、P4A—P4D-1 和 P4F-lite 的冻结只保护既有具名证据、fixture、schema 和历史
结果不被原地改写。冻结不禁止通过新版本、迁移和兼容接口建设持久 scheduler、事件
账本、课程 Graph、浏览器伴随驱动、发布恢复和近端结果观察。

## 2. 工作以推进为默认

- 用户明确产品目标后，普通、可逆、可验证的代码、迁移、测试、修复、浏览器检查、
  文档和允许范围内的数据处理自动继续。
- 一次成熟纵向切片内部不设置计划确认、设计评审、代码审查、测试审查或演示确认
  停门。检查发现的问题由当前执行直接修复并复验。
- review、Gate、ADR、preauth、candidate、receipt、测试 fixture 和历史失败是证据，
  不是新的授权机关。
- 单个目标或非关键分支受阻时，记录明确状态并继续其他独立线程；不得把局部页面超时
  扩大为整个课程周期或整个开发里程碑暂停。
- 产品能力、运行可靠性和研究证据可以是不同里程碑。只有宣称研究成果时才要求同步
  给出具名证据和复现入口；普通产品基础设施不以论文结果作为开工条件。
- 产品运行资格、事故和外部授权只限制相应运行能力与主张，不接管研究问题的排序；
  前瞻研究方向以
  [课程共同体促进研究纲领](源码/docs/COMMUNITY_FACILITATION_RESEARCH_DIRECTION_R1_2026-08-30.md)
  为准。

只有以下四类情况暂停并请求用户决定：

1. 将删除、覆盖或不可逆改变重要数据或用户工作；
2. 将产生当前运行策略未授权的真实发布、通知、消息、付款或其他外部副作用；
3. 将读取、发送或扩大使用未获授权的原始敏感正文、身份、凭据或私有映射；
4. 缺少一个会实质改变产品目标、研究问题、数据契约或对外承诺的用户选择。

权限缺失只阻断对应外部动作。其余实现、shadow、测试、异常入队和恢复验证继续进行。

## 3. 已授权的开发与测试表面

在用户给出的 cMOOC 测试平台和本机开发环境中，下列动作属于已授权开发范围，无需
逐次重新询问：

- Chrome、Computer Use、Playwright 或 API 的只读巡检；
- 导航、滚动、分区切换、打开详情、读取页面结构和受控网络观察；
- 本地数据库迁移、去正文事件/回执保存、Graph 与指标计算；
- 在真实编辑器中写入、回读和清除未提交草稿；
- 在 `realPublishEnabled=false` 下开发并测试发布、幂等、核对和恢复代码；
- 使用 synthetic adapter、shadow transport 或拦截网络验证外部写路径。

默认开发阶段不得点击发布、使用提交快捷键、发送论坛写请求或通知真实人员。只有
用户对当次外部动作明确授权，并且版本化 `AutonomyPolicy`、单动作 Permit、目标/
版本/内容/幂等绑定、写前重读、写后核对和紧急停止全部成立时，才可执行受控动作。
策略必须绑定课程、允许动作、预算、有效期、撤销状态和执行模式。

2026-07-31 的一次 L3 授权已消费并完成硬重锁。该历史成功、已消费 Permit 和 pending
outcome 窗不授予任何后续发布或通知权限。

课程入口必须来自显式 `CourseManifest`。不得使用静默默认 courseId；最终页面、API
返回和 manifest 不一致时只隔离该课程运行并报告。

## 4. 事件世界与模型边界

- 产品第一事实层称为 `Course Event World`：它由真实观察事件、严格时间、稳定引用、
  合法性、状态转移、提交和回放组成，不冒充 learned world model。
- observation 和 CandidateSet 只使用严格 `as-of` 证据；同一时点无法证明顺序的事件
  不制造虚假全序。
- 策略只输出结构化决定；机械 resolver 拥有目标合法性、forced WAIT、过期和预算
  判定；语言模型只实现已解析的 Intent/MoveSpec，不能控制时钟、候选、身份、预算、
  world commit 或发布权限。
- 每次运行形成追加式 Decision Tape，绑定观察、候选、决定、语言摘要、写前重读、
  执行回执、前后状态、结果窗口和哈希链。既有记录不回写为另一种结果，更正使用新
  事件追加。
- 动作条件 `ProspectiveWorldModel` 只有在真实结果积累后作为只读预测层加入；其输出
  必须密封、记录是否被策略读取，并能通过隐藏/置乱比较证明实际改变行动。

## 5. 数据与证据边界

- `01_原始数据` 只读；正式研究产物写入 `%LOCALAPPDATA%\cmooc-research` 的版本目录。
- Git 和普通归档不得包含论坛正文、私有索引、自然人映射、真实平台 ID、数据库、
  `.env`、token、Cookie、密码、auth-state 或可识别日志。
- 不读取或复述 `apiKey.txt`、接口说明中的凭据或其他秘密；认证由既有登录态、环境
  变量或受控 credential provider 提供。
- 不把 P4F 合成保真、离线调度、Graph 相似度、编辑器暂存或自动生成草稿写成真实
  学习效果或因果效应。
- 不绕过登录、验证码、平台权限或风控。

## 6. 反防御性研究推进

- 研究先提出最强且有依据的教育问题、发现和机制，再在相关命题旁说明必要边界；
  不用限制清单、运行事故或审批状态代替研究主故事。
- 证据边界决定可以声称什么，不禁止从真实情境形成描述、机制、竞争解释和新模型。
  零差异、不利结果和课程差异先作为可解释的研究发现处理。
- 教师和学习者参与定义促进机会、行动功能、责任分配与适切性判断，不只充当标签来源
  或结果对象；Graph 的描述、机制和设计价值不以预测增益为前提。
- 未经理论、决策成本或预注册支持的数值不得升级为研究停止门槛。产品可靠性与研究
  发现并行推进，只有确认性主张和真实外部动作使用相应资格条件。

## 7. 风险分层验证

- L0：文档、规则、局部纯函数——定向校验和 diff 检查。
- L1：一个纵向切片——相关单元/集成测试、类型检查和一次端到端场景。
- L2：新信任边界、持久迁移、浏览器执行或恢复——契约测试、故障注入和真实浏览器
  shadow 验证。
- L3：实际发布激活或公共协议——完整 verify/build、并发/幂等/结果不明核对和一次
  聚焦红队。

修复只重开受影响的验证维度。输入和依赖未变化时不重复全量审查；每个纵向里程碑
完成后统一验证一次。
