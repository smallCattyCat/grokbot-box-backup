# cMOOC 促进功能人工编码代码本 v1.1

冻结日期：2026-07-19（Asia/Shanghai）

## 版本边界

v1.1 是在 50 条人工快速试编码后形成的边界修订。试编码暴露了“信息丰富即促进”、“有问号即问题引导”、“长文分节即综合”等混淆。因此，v1.1 不是事前注册的原始代码本；使用 v1.1 修订的结果必须与 v1 快标分开保存，不得将两者写成独立双人一致性。

## 编码目标与单位

编码单位是一条主帖事件。判断的是该事件在发布当时是否用可定位行为支持他人或网络的连接、知识建构或持续参与。编码对象是“这一次行动”，不是作者的永久身份、人格、教师地位或智能学伴来源。

代码本与 CIE 学习交互层级相互独立。不得因为帖子复杂、篇幅较长或后来回复较多，就推断高阶认知、促进功能或作者身份。

## 盲法与证据边界

- 只看事件当时的帖子内容和必要的前序主题语境。
- 不看课程、作者、平台角色、来源类型、字数、中心性、最终点赞数或最终回复数。
- P95/P99 长帖是抽样入口，不是促进证据。
- 证据必须对应帖子实际完成的交往功能，不能把文章中“建议教师如何促进”当成该帖本身已经完成的促进行为。

## 第一步：是否存在促进功能

`facilitation_present` 只能填写：

- `yes`：至少一种促进功能有明确、可定位的行为证据；
- `no`：主要是个人陈述、作业提交、自我展示、无语境转发或其他内容，没有可识别的促进他人/网络行为；
- `uncertain`：缺少必要语境，或证据不足以在 `yes/no` 间判断。

只有 `yes` 才填主要和次要功能。如果仅能说“这篇内容可能对别人有用”，但找不到具体的分享、引导、连接、组织或支持行为，不应自动判 `yes`。

## 第二步：促进功能标签

| 标签 | 必要证据 | 不足以构成该标签 |
|---|---|---|
| `resource_seeding` | 明确引入与主题相关、他人可继续学习或连接的资源、案例、工具或操作方案 | 只是长、信息多或结构完整；只粘贴链接且无主题关联线索 |
| `question_guiding` | 向预期参与者提出可回应的开放、分步或澄清问题，目的是推动后续表达或探究 | 修辞性问句、标题问句、文章自问自答、测验式检查答案 |
| `idea_bridging` | 明确指出至少两个可识别观点、帖子、概念、参与者或实践场景之间的关系 | 文章包含多个部分、并列多个观点或笼统地把 AI 与教育放在一起 |
| `amplification` | 识别并突出某个已存在的他人贡献，为其增加可见度或后续讨论机会 | 推荐一篇文章；介绍“应该精选好资源”这种方法；普通赞美 |
| `synthesis` | 整合多个已存在的讨论、贡献或证据，进行比较、归纳并形成可继续推进的结构 | 总结自己的一句心得；长文分节；整理单一文章或自己的原帖 |
| `cognitive_challenge` | 用反例、矛盾、边界条件或替代解释促使某个已表达观点被重新考虑 | 泛泛说“需要反思”、无理由反对或人身否定 |
| `affective_support` | 对已出现的困惑、挫败、孤立或参与困难做具体回应，并提供鼓励、任务拆解或可行支持 | 模板式“加油”、泛化表扬或只营造热情语气 |
| `coordination` | 明确组织当前或后续活动，给出参与路径、时间、步骤、角色或任务分配 | 已结束活动的纯回顾；不支持参与的单向行政通知 |
| `peer_exchange` | 以平等参与者身份分享自己可回应的经验，并明确邀请他人比较、补充或互学 | 普通作业、通用知识文章、单向转发、只出现“分享”二字但无自身经验或互学邀请 |

## 主要与次要功能

- `primary_function` 是最能解释该帖当下交往作用的一个标签，不是帖子中出现次数最多的关键词。
- `secondary_functions` 只在另一功能也有独立、可定位证据时填写；不得根据可能用途“顺手多选”。
- 如果一条导学帖同时提供资源、提出问题并安排任务，以其最主要的行动目标选主标签，其余功能仅在有具体证据时列为次要。

## 置信度

- `0.90`：证据直接、主次标签边界清楚，且没有合理竞争解释；
- `0.70`：存在功能证据，但主要功能有一种合理替代解释；
- `0.50`：证据有限或依赖缺失语境，必须复核；
- `0.30`：证据很弱，原则上选 `uncertain`。

多选两个及以上次要功能时，编码者应主动检查每个标签是否都有独立证据；标签多不意味着置信度高。

## 修订后复核规则

1. v1 的 50 条快速编码保留为 `human_fastpass_v0`，不覆盖。
2. v1.1 先对预先记录的高风险边界项进行定向复核；这是质量修订，不是随机信度样本。
3. 模型标注必须看不到人工标签；人工最终裁决时可查看分歧，但必须记录裁决理由码。
4. 快标、定向复核、模型盲标和最终裁决必须使用不同状态和文件，不得互相伪装。

## 禁止性规则

- 禁止依据长帖、网名、职务文字或文风猜测历史学伴、教师或促进者身份。
- 禁止把促进者帖子作为学生心理状态、人格或认知层级的直接证据。
- 禁止用后续交互结果反向修正当时的促进功能标签。
- 禁止将未裁决的人工标签或模型弱标签直接用于在线自动干预策略。
