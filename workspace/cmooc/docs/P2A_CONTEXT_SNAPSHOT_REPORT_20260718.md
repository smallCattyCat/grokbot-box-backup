# P2a：版本化上下文快照与外显角色策略

日期：2026-07-18

## 结论

P2a 已把草稿流水线从“持续改写学伴心理状态”调整为任务内、可追溯的 `Observation → Inference → Expression`（O-I-E）结构。它是面向后续世界模型研究的最小时间索引上下文层，不宣称已经实现可预测完整环境演化的世界模型。

本次没有启用真实发布、没有调用真实论坛写入链路，也没有使用尚未完成的 P1f 人工标签训练或调参。

## 做了哪些减法

- `mental-state-agent` 不再读取或更新 `CompanionProfile.currentMentalStateJson`；旧字段只作为兼容性基线保留。
- 不把任务内的共情、好奇、挑战度和温暖度解释为稳定人格或心理状态，而是限定为本次回复的表达调节量。
- 不把课程聚合信号写成学习者身份或心理诊断；推断快照固定记录 `nonDiagnostic=true` 与 `stablePersonalityClaimed=false`。
- 不把帖子标题、正文复制进上下文快照，减少敏感内容重复存储。
- 不因长帖、平台角色或单次行为自动推断教师、促进者或能力等级。

## O-I-E 契约

### Observation

- 版本：`agent-observation-v1`。
- 固定 `asOfAt` 截止时点、课程、任务、帖子、目标用户与来源批次。
- 帖子计数优先读取截止时点前最后一条 `ForumPostSnapshot`；缺少安全历史来源时拒绝回放，而不是使用当前值冒充历史值。
- 学习者课程画像只允许使用 `generatedAt <= asOfAt` 且证据时间不晚于截止时点的记录。
- 仅保存计数、来源和时间，不复制原帖正文。

### Inference

- 版本：`agent-inference-v1-rules`。
- 保存已有 CIE、情绪、讨论潜力、孤立度等规则信号，并明确其为假设而非诊断。
- 保存任务内表达调节状态，不写回全局学伴档案。

### Expression

- 版本：`companion-expression-policy-v1`。
- 学伴角色被定义为名称、外显定位、语气与角色边界。
- 提示词明确禁止把该策略表述为真人身份、稳定人格或已知的学习者心理信息。

## 数据库与可追溯性

新增 `AgentContextSnapshot`：

- 每个任务按 `revision` 递增，`(taskId, revision)` 唯一。
- 同时记录三层版本号、`asOfAt`、来源批次与 `futureInformationUsed=false`。
- 当前业务流水线只追加、不更新快照；数据库管理员仍可直接操作 SQLite，因此这里是应用层追加式约束，不夸大为物理不可篡改存储。
- `AgentRun` 的表达智能体输入记录所引用的快照 ID，可从草稿追溯到当时的证据边界、推断与表达策略。

## 后续研究边界

P2a 为后续做“基于历史论坛状态生成可检验介入”提供了数据结构，但还缺少效度证据。下一步应按顺序推进：

1. 完成 P1f 双人盲标和分歧裁决，报告一致性与不确定性，不人为制造标签。
2. 用已裁决的促进功能标签检验调度与表达策略，而不是训练“学生人格”。
3. 在多个课程/时间窗口做只使用历史信息的回放评估，比较无介入、规则介入和上下文介入。
4. 若能提供经授权的历史学伴/系统账号清单，再单独评估其网络功能；在此之前保持 `unknown`，不从文风或篇幅猜身份。
