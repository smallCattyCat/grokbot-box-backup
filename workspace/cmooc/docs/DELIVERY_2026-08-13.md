# cMOOC Course Agent Workbench 交付说明

交付日期：2026-08-13

## 本次交付

本包提供一套可运行、可迁移、可测试的课程运营智能体 Workbench：操作者以自然语言提出任务。已知任务继续使用课程支持缺口、研究证据包或课程排期审阅的稳定计划；未命中预设或同时跨多个任务族的目标进入 MVP 开放规划，由模型从现有课程工具中选择 1–8 步短计划。两种路径都创建不可变安全目标与规范计划，保存工具调用回执与验证结果，并交付版本化成果。

开放规划 MVP 已完成一条真实混合任务验收：“先检查课程排期，再生成研究证据包”会组合课程上下文读取、快照读取、研究包生成、排期读取和排期审查成果生成，共 5 步、2 个版本化成果。原始自然语言目标只在当前执行中使用，不写入安全目标、计划、数据库快照或会话交接文件。

最终答复投影已修复“单行触发整段删除”的问题：疑似论坛正文、内部标识或命令只删除对应行，安全的实际答案、草稿和方案仍作为首要交付展示；模型也被要求先给成果，不能用“已形成”或执行清单代替内容。

课程支持缺口链已经覆盖：课程状态读取、机会筛选、证据核验、Intent 与草稿生成、写前重读、受信任编辑器暂存、逐字回读、清空、交付包生成，以及失败后的核对与恢复。真实发布、发送和通知保持关闭。

Artifact Workspace 已支持安全元数据浏览、一次性正文预览、受保护正文修订、服务端重新验证、不可变 vN+1 版本、版本 diff 和持久选择指针。选中新版本后，旧版本不能再进入 STAGE。

## 配置提示

- 默认情况下 Workbench 的真实平台 STAGE provider 不启用，课程读取、分析、生成和成果管理仍可工作。
- MVP 开放规划只选择现有 L0 只读工具，以及研究包/排期审查两类 L1 可恢复成果工具；不会把任意目标直接升级为平台暂存或发布动作。
- `LLM_MODE=real` 时开放规划使用已配置的 JSON 规划模型；mock 模式保留确定性的混合任务演示与测试路径。
- 受信任零发布 STAGE 使用服务端 provider，并要求 `CMOOC_WORKBENCH_TRUSTED_STAGE_ENABLED=1`。
- 可逆 STAGE 自动执行还需额外设置 `CMOOC_WORKBENCH_AUTO_REVERSIBLE_STAGE_ENABLED=1`；该设置不会启用真实发布。
- 任何真实发布仍由独立发布能力与项目硬锁控制，本交付包未携带真实发布授权。
