# P1e 本地盲审查看器设计与安全规范

## 定位

P1e 是独立于 Next.js、Prisma 和自动发布链路的本地研究工具。它只服务于 P1d 已抽中的主帖，由编码者阅读去身份内容并填写促进功能标签。工具不提供账号检索、角色查看、网络指标、最终互动结果或任何发布能力。

视觉规范来源：[P1e 盲审界面概念图](design/p1e-blind-review-concept.png)。

## 页面结构

1. 顶栏：工具名称、完成进度和“仅本机 · 身份已隐藏 · 不保存正文”。
2. 左栏：只显示盲化项目的显示序号和完成状态。
3. 阅读区：显示“审阅项目 N”、净化后的标题和正文；不显示课程、作者、角色、来源、字数、点赞或回复。
4. 编码区：存在/不存在/不确定、主要功能、次要功能、置信度、上一条、保存并下一条。
5. 导出：全部项目完成后才允许导出与 P1d 校验器兼容的 CSV。

## 内容访问边界

- 服务只绑定 IPv4 127.0.0.1，不接受远程主机参数。
- API 要求随机会话令牌；令牌放在 URL fragment 中，不进入 HTTP 日志、历史请求或查询参数。
- 严格校验 Host 与同源请求，防止 DNS rebinding 和跨站调用。
- 页面使用 Cache-Control: no-store、严格 CSP、frame-ancestors 'none' 和 X-Content-Type-Options: nosniff。
- 启动时校验研究数据库 SHA-256、数据指纹及 8 个原始 Excel 哈希；任一不匹配即拒绝运行。
- 只为 P1d 私有映射中的 300 个主帖计算 HMAC 定位；正文仅存在于进程内存和浏览器当前页面。
- 页面关闭或进程退出后不保存正文；草稿文件只保存盲化项目号和标签。
- 读取课程成员真实姓名和网名仅用于内存替换，替换表不写盘、不返回前端。
- 邮箱、电话、证件号、外部账号、凭据和 URL 在显示前再次净化。
- 自动替换用于降低编码者识别身份的风险，不等于对自由文本匿名性的绝对保证。审阅器只能由获准接触该匿名化数据集的编码者在受控本机使用；单条替换达到 20 处时界面会提示语义可能受损。

## 状态与导出

草稿以独立 JSON 原子写入 %LOCALAPPDATA%\cmooc-research\p1e，只包含：项目号、存在性、主要/次要功能、置信度、编码者代号、轮次和编码状态。导出 CSV 的列顺序必须与 BLIND_COLUMNS 完全一致，并通过 research:review:validate 后才可进入裁决。

## 明确禁止

- 不把服务挂载到现有 /api 或管理后台。
- 不把原始正文、净化正文、身份替换表或会话令牌写入日志、SQLite、Git、LocalStorage 或 Service Worker。
- 不显示或推断教师、学伴、学习者身份。
- 不展示后续回复、点赞、中心性或其他未来条件信息。
- 不从界面直接写入 event_function_score，更不触发自动干预或发布。
