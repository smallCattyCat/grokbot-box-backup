# P2b：O-I-E 只读追溯界面与脱敏 API

日期：2026-07-19（Asia/Shanghai）

## 结论

P2b 已把 P2a 的 `Observation → Inference → Expression` 快照接入干预队列。每个已有草稿默认显示最新 revision，并可展开查看当时的可见事实、非诊断性推断和外显角色策略。该区域没有编辑、重算、入队或发布能力，不改变真实发布开关。

## 数据最小化

- 页面与 `GET /api/interventions/{id}/context` 共用白名单序列化器。
- API 不直接返回数据库中的三个 JSON 字段，而是逐层挑选允许字段。
- 意外加入的正文、隐藏提示词、内部字段和角色对象扩展字段会被丢弃。
- 当前允许字段包括版本、revision、截止时点、来源、计数、已有规则信号、任务内调节量和外显角色边界。
- 响应固定使用 `Cache-Control: no-store`；不存在的任务返回 404。

## 界面语义

- Observation 显示来源、观测时间、帖子计数、课程活动计数及“原文是否复制”。
- Inference 显示 CIE、情绪、讨论潜力和孤立信号，并显式标注“非诊断性假设”和“未声明稳定人格”。
- Expression 显示外显角色、语气、本次焦点和角色边界，并显式标注“未持久改写人格”。
- 顶部同时显示三层版本号、revision 和是否使用未来信息。

## 自动验证

- 新增白名单序列化单元测试：构造包含伪造正文、隐藏提示词和秘密角色字段的快照，确认追溯输出全部丢弃。
- 集成测试确认 revision 按 2、1 倒序返回，API 为 `no-store`，404 正确，且响应不含帖子标题或正文。
- `npm run verify` 通过：8 个单元测试、3 个集成测试、22 个研究脚本测试，以及操作员契约、TypeScript 和 ESLint 检查全部通过。
- `npm run build` 通过，包含新的动态 API route；23 个页面成功生成。既有 webpack 缓存快照警告仍存在，不影响构建结果。

## 研究边界

追溯界面增强的是可审计性，不证明推断规则本身有效。CIE、情绪、讨论潜力和孤立度仍是待验证信号；P1 人工校准与后续时间留出评估未通过前，不能把本界面作为模型效度证据。
