# AGENTS.md

## 权威入口与目标

本仓库的默认目标是交付可长期运行的 **cMOOC 课程社区自主促进产品**，不是停留在
离线算法、一次性演示或逐条人工审批工具。教师/课程运营者设置目标、预算和边界，
系统持续执行“感知—择机—促成—让位”，人类以策略制定者和长期审核者身份介入，
而不是每次守在控制台前批准。

处理任务前按以下顺序确定当前事实：

1. 上层 [项目规则](../PROJECT_RULES.md)：授权边界与持续执行原则；
2. [产品当前状态](docs/PRODUCT_CURRENT.md)：唯一当前里程碑和下一纵向切片；
3. [自主产品开发总计划](docs/AUTONOMOUS_PRODUCT_MASTER_PLAN.md)：产品架构与路线；
4. [研究纲领](docs/COMMUNITY_FACILITATION_RESEARCH_DIRECTION_R1_2026-08-30.md)：前瞻问题与贡献；
5. [当前研究工作流](docs/CURRENT_RESEARCH_WORKFLOW.md)：冻结证据；
6. [代理决策规则](docs/AGENT_DECISION_POLICY.md)：Proceed / Ask 边界。

P3、P4 及其固定 fixture、审计结果和既有研究结论保持冻结，含义是**历史证据不可
被新实现倒改**，不意味着禁止新增版本、迁移层、真实课程观察、持久调度、世界
状态、故障恢复或自动执行基础设施。新能力另建版本，旧证据作为回归基线。

## 默认持续执行

- 用户要求开发时，先读现状和必要契约，随后直接实现、验证、修复，直到形成成熟
  可运行结果或遇到真正不可替代的外部阻塞；不要在计划、页面、模块或测试之间
  反复请求确认。
- 审查、代码评议和测试是同一执行回路中的输入：发现范围内问题就修复并重跑相关
  检查，不把“等待审查”设置为阶段状态。
- 产品里程碑、可靠性里程碑和研究证据里程碑可以不同步。并非每个产品切片都必须
  立即产生论文结果；只有被命名为研究阶段进展时，才要求产品、证据、复现三项
  同时成立。
- 优先完成一个真实纵向切片，再提炼它已经需要的抽象。保留多智能体的责任分工，
  不新增人格化委员会、逐层审批或仅用于交接的角色。

## 产品黄金路径

```text
课程清单与观察游标
→ API / Chrome / Computer Use 只读采集
→ ObservedEventLedger 与 Course Event World
→ 严格 as-of 状态、连接图和 CandidateSet
→ INTERVENE / WAIT / ABSTAIN / YIELD
→ Intent + MoveSpec
→ 可替换模型生成草稿
→ 发布前重读与真人连接检测
→ 撤回让位，或在策略授权下幂等提交
→ 去正文 Decision Tape 与近端结果观察
```

当前唯一下一切片由 `docs/PRODUCT_CURRENT.md` 指定。课程必须通过显式
`CourseManifest` 绑定 origin、courseId、入口、适配器、运行模式和策略版本；
不得在代码中设置会误巡其他课程的默认 `courseId`。

Course Event World 是可审计的事件账本和派生状态，不要把它冒充已学习的
“世界模型”。预测、反事实或风险估计只能作为后续可版本化
`ProspectiveWorldModel`，且不能覆盖观察事实或决策带。

四类责任必须分离：

1. policy 决定何时、对谁、为什么以及允许的动作；
2. resolver 把逻辑目标解析为当前页面/API 目标；
3. semantic realizer 生成可替换、可追溯的文本草稿；
4. committer 只执行已授权动作并核验远端结果。

所有决策、重读、撤回、提交尝试和结果观察进入去正文 `Decision Tape`。近端指标
至少覆盖首个外部真人回复、作者再参与、回复深度/功能摄取、新作者覆盖、重复触达、
自动动作结果、人工抽检结论和审阅耗时；离线动作不能登记为真实干预。

## 测试平台与自主模式

- 当前测试课程可使用平台 API、Chrome、Computer Use、Playwright 或其组合做
  登录态观察、导航、分区切换、滚动、打开帖子、回复展开、结构读取、状态核验和
  故障恢复。API 可用部分应复用，界面代理承担缺失或变化部分。
- 开发阶段允许把草稿写入测试平台编辑器、回读并清空，但不得点击发布、使用提交
  快捷键或触发真实通知。每次都要在动作前后核验页面与目标身份。
- 可以完整开发发布、幂等、重试、恢复和核对能力，但硬锁保持
  `realPublishEnabled=false`。真正启用 AUTO 发布必须由版本化
  `AutonomyPolicy` 明确课程、账号、动作、预算、时间窗、停机条件和有效期；不存在
  有效策略时必须 fail closed。
- 模式统一为 `OBSERVE / SHADOW / STAGE / AUTO / HALTED`。当前默认是 SHADOW；
  STAGE 仅允许不提交的编辑器演练；AUTO 的实现可以提前完成，但激活是独立外部
  效果授权。
- 某个目标因版本变化、真人回复、登录失效或证据不足而失败时，只撤回/降级该目标，
  记录原因并继续巡检其他目标；不得把单项失败升级成整个课程任务中断。

## 仅在必要时暂停

只有当前验收不可替代且属于下列情形时才询问；否则隔离该动作并继续：

- 真实发布、通知真实人员或启用尚无有效 `AutonomyPolicy` 的外部写入；
- 向外部模型发送论坛正文、私有索引、身份信息或行级敏感派生物；
- 不可逆删除/覆盖原始数据、正式数据、共享库或用户工作；
- 缺少不可替代的凭据、账户权限或平台所有者决定；
- 互斥选择会改变研究问题、数据契约、证据含义或对外承诺。

询问只针对一个受阻外部动作，并同时说明已完成的安全部分。授权缺失不能阻塞同一
目标的观察、影子决策、草稿、测试、故障恢复实现和本地证据生成。

## 数据、研究与安全边界

- `01_原始数据` 只读；正式研究产物写入
  `%LOCALAPPDATA%\cmooc-research` 的版本目录，不写入 Git。
- Git 不得包含论坛正文、私有索引、真实平台 ID、数据库、`.env`、token、Cookie、
  密码、`auth-state`、截图中的敏感内容或临时产物。
- 不读取、复述或记录 `apiKey.txt`、学伴操作接口文本中的凭据。不得绕过登录、
  验证码、平台权限或风控。
- 不调用本地模型。只有当前任务明确授权时，才可运行
  `npm run research -- annotate --authorize` 或相应在线研究发送流程；授权不得
  继承。
- 特征严格遵守 `as-of`；P3A v1 的 2024/2025 开发/留出定义冻结，后继研究中
  2025 已暴露，仅作历史基准。
- P4F 合成场景、mock/fixture、离线策略动作、shadow 草稿和参考一致性只可证明
  工程或协议性质，不得写成真实干预、教育效果或因果效应。
- 促进功能是事件级动作变量，不是教师、学习者、促进者或学伴的固定等级身份。

## 实现与验证

- Git 根目录是本文件所在的 `源码/`。沿用既有 adapter、gateway、state machine、
  P3A 调度证据、P4 协议与 `/review` 黄金路径；重构时加兼容层，不改写冻结证据。
- 浏览器自动化必须使用语义定位、页面身份核验、动作后置条件和可恢复状态；选择器
  漂移应显式降级，不能静默把错误页面当成功。
- 验证与风险相称。规则变更运行 `npm run verify:agent-guidance`；单模块代码运行
  相关测试、`npm run type-check` 和 `npm run lint`；状态机、执行内核或跨模块协议
  运行 `npm run verify`；生产构建路径变化再运行 `npm run build`。
- 测试或审查失败先判断是否由本次修改引入；范围内则修复，既有无关失败如实记录，
  不用它阻止当前可验证成果。
- 最终交付说明实际可运行能力、验证证据、当前模式和仍需外部策略授权的动作。只有
  行为、入口、契约或操作方法改变时才更新当前文档。
